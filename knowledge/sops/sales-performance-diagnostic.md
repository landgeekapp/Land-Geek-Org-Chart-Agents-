# SOP: Sales Performance Diagnostic

**Owner**: Head of Sales
**Last Updated**: [Date]
**Version**: 1.0

## Purpose
Systematic framework for diagnosing individual and team sales performance issues.

## Diagnostic Checklist

### Individual Performance Analysis

#### Data Collection (Last 2 Weeks)
- [ ] **Close Rate by Closer**
  - Jon Burnett: ___%
  - Scott Rossman: ___%
  - Mike Zaino: ___%
  - Team Average: ___%

- [ ] **Call Metrics**
  - Average call duration (Jon vs. others)
  - Number of calls per closer
  - Show rate by closer
  - Close rate by closer

- [ ] **Deal Metrics**
  - Average deal size (Jon vs. others)
  - Discount usage (% of deals, average %)
  - Sales cycle length (days to close)
  - Win/loss ratio

- [ ] **Lead Source Analysis**
  - Close rate by lead source (for each closer)
  - Lead quality score distribution
  - Conversion by setter (Sebastian vs. Kester)

#### Pattern Identification
- [ ] **Timeline Analysis**
  - When did performance drop start?
  - Any correlation with specific day/week?
  - Any external events (pricing change, competitor launch)?

- [ ] **Lead Quality Check**
  - Are lower-scored leads going to underperformer?
  - Budget qualification accuracy (setters)
  - Lead scoring accuracy (are 7.5+ actually qualified?)

- [ ] **Call Review** (if recordings available)
  - Objection handling effectiveness
  - Value proposition clarity
  - Closing technique
  - Energy/confidence level

### Root Cause Hypotheses

#### Hypothesis 1: Objection Handling Deteriorated
**Evidence:**
- [ ] Higher objection frequency in lost deals
- [ ] Specific objection types not being handled well
- [ ] Comparison: How do top performers handle same objections?

**Action if confirmed:** Coaching + updated scripts

#### Hypothesis 2: Competitive Landscape Changed
**Evidence:**
- [ ] New competitor launched/announced
- [ ] Competitor pricing changed
- [ ] Competitive mentions increased in lost deals
- [ ] Specific competitors mentioned more frequently

**Action if confirmed:** Competitive response framework

#### Hypothesis 3: Lead Routing Issue
**Evidence:**
- [ ] Lower lead scores routed to underperformer
- [ ] Budget qualification inaccurate
- [ ] Lead source quality varies by closer

**Action if confirmed:** Fix routing logic + setter training

#### Hypothesis 4: Personal/Confidence Issue
**Evidence:**
- [ ] Energy level dropped in calls
- [ ] Personal circumstances affecting performance
- [ ] Burnout indicators

**Action if confirmed:** 1-on-1 support + temporary load adjustment

## Usage
Run this diagnostic when:
- Individual closer performance drops >5 points
- Team conversion rate drops >3 points
- Sudden performance change (within 1 week)
- Monthly performance review flags issues
