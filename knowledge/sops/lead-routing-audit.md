# SOP: Lead Routing Audit

**Owner**: Head of Sales / Head of Operations
**Last Updated**: [Date]
**Version**: 1.0

## Purpose
Ensure leads are distributed fairly and routed to the right closer based on qualification and capacity.

## Audit Checklist

### Lead Distribution Analysis

#### Volume Distribution (Last 2 Weeks)
- **Jon Burnett**: ___ leads (___% of total)
- **Scott Rossman**: ___ leads (___% of total)
- **Mike Zaino**: ___ leads (___% of total)

**Target**: Equal distribution (±5% variance acceptable)

**Issues to Flag:**
- [ ] One closer getting significantly more/fewer leads
- [ ] Unbalanced distribution by day of week
- [ ] Unbalanced distribution by lead source

#### Lead Quality Distribution

**Average Lead Score by Closer:**
- **Jon Burnett**: ___ (average score)
- **Scott Rossman**: ___ (average score)
- **Mike Zaino**: ___ (average score)

**Target**: Equal average scores (±0.3 points acceptable)

**Score Distribution:**
- [ ] Are lower-scored leads (7.5-8.0) going to one closer?
- [ ] Are higher-scored leads (9.0+) going to one closer?
- [ ] Is distribution random or systematic?

#### Lead Source Distribution

**By Lead Source:**
- **Source A**: Jon ___, Scott ___, Mike ___
- **Source B**: Jon ___, Scott ___, Mike ___
- **Source C**: Jon ___, Scott ___, Mike ___

**Analysis:**
- [ ] Are certain sources performing better?
- [ ] Are better sources going to specific closers?
- [ ] Is distribution balanced across sources?

### Setter Performance Analysis

#### Budget Qualification Accuracy

**Sebastian Perez:**
- Leads set: ___
- Budget qualified: ___
- Budget accuracy: ___% (actual budget vs. stated)
- Close rate of leads set: ___%

**Kester Harvey:**
- Leads set: ___
- Budget qualified: ___
- Budget accuracy: ___% (actual budget vs. stated)
- Close rate of leads set: ___%

**Issues to Flag:**
- [ ] Setters qualifying leads with insufficient budget
- [ ] Budget qualification not matching closer experience
- [ ] One setter's leads converting better than other

#### Lead Scoring Accuracy

**Review: Are 7.5+ leads actually qualified?**

**Sample Check (Last 20 SQLs):**
- [ ] Lead Score: 7.5-8.0 → Actual qualification: ___% qualified
- [ ] Lead Score: 8.1-9.0 → Actual qualification: ___% qualified
- [ ] Lead Score: 9.1+ → Actual qualification: ___% qualified

**Issues to Flag:**
- [ ] Low-scored SQLs (7.5-8.0) not actually qualified
- [ ] High-scored SQLs (9.0+) still not closing
- [ ] Scoring criteria need adjustment

### Routing Logic Review

#### Current Routing Method
- [ ] Round-robin (equal distribution)
- [ ] Skill-based (by closer strength)
- [ ] Capacity-based (by availability)
- [ ] Manual assignment
- [ ] Other: [Description]

#### Routing Rules
- [ ] Are rules documented?
- [ ] Are rules being followed?
- [ ] Are there exceptions? (List)

#### Routing System
- [ ] Automated (CRM/workflow)
- [ ] Manual (human assignment)
- [ ] Hybrid

**If Automated:**
- [ ] Review workflow logic
- [ ] Test routing rules
- [ ] Verify no bugs/errors

**If Manual:**
- [ ] Review assignment patterns
- [ ] Check for bias/unfairness
- [ ] Document assignment criteria

## Corrective Actions

### If Distribution is Unbalanced

**Action 1: Adjust Routing Logic**
- [ ] Update CRM workflow/rules
- [ ] Ensure equal distribution going forward
- [ ] Monitor for 1 week to verify

**Action 2: Rebalance Current Pipeline**
- [ ] Identify over-allocated closer
- [ ] Identify under-allocated closer
- [ ] Reassign leads (if appropriate)
- [ ] Communicate changes to team

### If Lead Quality is Unbalanced

**Action 1: Fix Scoring**
- [ ] Review lead scoring criteria
- [ ] Adjust scoring weights if needed
- [ ] Re-train setters on qualification
- [ ] Update scoring algorithm

**Action 2: Fix Setter Qualification**
- [ ] Train setters on budget qualification
- [ ] Implement qualification checklist
- [ ] Add quality checks before handoff
- [ ] Monitor setter performance

### If Routing System Has Issues

**Action 1: Fix Automation**
- [ ] Debug routing workflow
- [ ] Test with sample leads
- [ ] Deploy fix
- [ ] Monitor for 1 week

**Action 2: Improve Manual Process**
- [ ] Document assignment criteria
- [ ] Create assignment checklist
- [ ] Implement quality checks
- [ ] Regular review meetings
