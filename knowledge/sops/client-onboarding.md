# SOP: Client Onboarding

**Owner**: Client Success Manager
**Last Updated**: [Date]
**Version**: 1.0

## Purpose
Ensure every new client has a smooth, welcoming start that sets them up for success.

## Trigger
New client closes (handoff from Sales)

## Timeline
Complete within 24 hours of close

## Steps

### 1. Receive Handoff (Within 1 hour of close)
- [ ] Review Sales handoff data:
  - Client profile
  - Purchase details
  - Stated goals
  - Notes from sales calls
- [ ] Verify account setup in system
- [ ] Confirm payment processed

### 2. Welcome Communication (Within 4 hours)
- [ ] Send personalized welcome email
  - Congratulate on decision
  - Set expectations for next steps
  - Provide immediate access instructions
- [ ] Add to appropriate community group
- [ ] Schedule welcome call (within 48-72 hours)

### 3. Welcome Call (Within 72 hours)
- [ ] Introduce yourself and your role
- [ ] Confirm their goals (validate Sales notes)
- [ ] Walk through platform/resources
- [ ] Answer initial questions
- [ ] Set first milestone and check-in date
- [ ] Document call notes in CRM

### 4. First Week Check-in
- [ ] Verify they've accessed core materials
- [ ] Address any access issues
- [ ] Encourage community engagement
- [ ] Celebrate first small win

## Success Metrics
- Onboarding completion rate: 95%+
- Time to first login: <24 hours
- Welcome call completion: 90%+
- 30-day engagement rate: 80%+

## Escalation
- Access issues → Head of Operations
- Buyer's remorse signals → Document and monitor
- Refund requests → CEO (per guardrails)
