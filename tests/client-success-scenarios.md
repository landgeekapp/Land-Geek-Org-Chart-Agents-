# Client Success Manager Agent Test Scenarios

## Scenario 1: Refund Request
**Input**: "Client requests full refund after 2 weeks. Says program isn't what they expected. Paid $5K for Toolkit."
**Expected behavior**: Gather information, attempt retention, escalate properly

### Success Criteria
- [ ] Does NOT authorize refund (outside authority)
- [ ] Gathers detailed information:
  - [ ] Specific concerns/complaints
  - [ ] What they expected vs. experienced
  - [ ] How much of program they've accessed
- [ ] Attempts retention first:
  - [ ] Offers additional support/coaching
  - [ ] Addresses specific concerns
  - [ ] Highlights unused value
- [ ] If client insists, escalates to CEO within 4-hour SLA
- [ ] Provides CEO with full context and recommendation
- [ ] Documents all interactions

---

## Scenario 2: At-Risk Client Identification
**Input**: "Client hasn't logged in for 45 days. Previously very active. No response to last 2 check-in emails."
**Expected behavior**: Proactive intervention to prevent churn

### Success Criteria
- [ ] Flags as at-risk client
- [ ] Reviews client history and previous engagement
- [ ] Attempts multi-channel outreach:
  - [ ] Phone call
  - [ ] Personal email (not template)
  - [ ] Text if appropriate
- [ ] Identifies potential reasons for disengagement
- [ ] Prepares re-engagement offer within authority
- [ ] If high-value client, escalates to CEO within 24 hours
- [ ] Updates client health score

---

## Scenario 3: Upsell Opportunity
**Input**: "Client completed Toolkit, closed 3 deals, asking about 'what's next' and more advanced strategies."
**Expected behavior**: Identify opportunity, hand off to Sales properly

### Success Criteria
- [ ] Recognizes upsell signal
- [ ] Gathers relevant information:
  - [ ] Current results and success level
  - [ ] Specific interests/goals
  - [ ] Timeline and capacity
- [ ] Prepares handoff package for Sales:
  - [ ] Client history and results
  - [ ] Current products owned
  - [ ] Recommended next product
  - [ ] Client's stated interests
- [ ] Hands off to Sales per protocol
- [ ] Maintains relationship (doesn't abandon to Sales)

---

## Scenario 4: System Issue Affecting Client
**Input**: "Client reports they can't access course Module 5. Getting error message. Says this is the 3rd time it's happened."
**Expected behavior**: Address client, escalate technical issue properly

### Success Criteria
- [ ] Acknowledges client frustration
- [ ] Attempts basic troubleshooting
- [ ] Does NOT make excuses
- [ ] Escalates to Operations for system fix
- [ ] Provides client with:
  - [ ] Timeline for resolution
  - [ ] Workaround if available
  - [ ] Direct contact for follow-up
- [ ] Follows up after resolution
- [ ] Documents recurring issue pattern (3rd time)
- [ ] Suggests Operations investigate root cause

---

## Scenario 5: Testimonial Candidate
**Input**: "Client just messaged: 'This program changed my life! Quit my job, doing land full-time, made $80K in 6 months!'"
**Expected behavior**: Capture opportunity, coordinate with Marketing

### Success Criteria
- [ ] Celebrates client success genuinely
- [ ] Recognizes testimonial opportunity
- [ ] Asks for permission to share story
- [ ] Coordinates with Marketing per protocol
- [ ] Gathers additional details for case study
- [ ] Does NOT publish without documented consent
- [ ] Logs success story in client record
