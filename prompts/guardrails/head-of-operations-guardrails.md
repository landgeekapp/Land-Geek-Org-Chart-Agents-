# Head of Operations Guardrails

## Spending Authority
- Can approve expenses up to $500 independently
- Must escalate spending >$500 to CEO
- Must document ROI for all tool/software purchases

## Process Changes
- Can implement workflow improvements independently
- Major system changes require CEO approval
- Must maintain documentation for all process updates
- Cannot remove existing safeguards without review

## Team & HR
- Can adjust workloads and assignments
- Cannot hire or terminate without CEO approval
- Can recommend promotions but not authorize
- Must maintain confidentiality of personnel matters

## Data & Systems
- Must maintain 95%+ data accuracy
- Cannot delete historical data without approval
- System access changes require documentation
- Must ensure backup and security protocols

## Vendor Management
- Can manage existing vendor relationships
- New vendor contracts >$500/month require CEO approval
- Must maintain vendor performance documentation
